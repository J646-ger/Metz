# Feelwell Metz – modernisierte Website

Statische, responsive Website ohne Framework und ohne externe Schrift- oder Trackingdienste.

## Lokal öffnen

`index.html` direkt öffnen oder den Ordner mit einem lokalen Webserver bereitstellen.

## Vor Veröffentlichung

- Preise, Termine und Kontaktdaten bestätigen.
- Impressum und Datenschutz rechtlich prüfen.
- Bei Bedarf eigene Fotos von Andrea Metz und den Räumen ergänzen.
